# 효과음 라이브러리 (참고 숏폼 3편에서 추출)

참고 영상(같은 채널 숏폼 3편)의 오디오에서 **나레이션이 없는 구간**만 골라 잘라낸 효과음 모음이다.
전부 `loudnorm=I=-16:TP=-1.5` 로 레벨을 맞추고 앞뒤 페이드를 넣어 그대로 얹어 쓸 수 있게 했다.

출처(분석에 쓴 원본):
- `https://www.youtube.com/shorts/_sQKXLJwFyE`
- `https://www.youtube.com/shorts/pOTb3oluokg`
- `https://www.youtube.com/shorts/NRbCOEjBfoc`

## 분류

| 폴더 | 개수 | 소리 | 쓰는 자리 |
|---|---|---|---|
| `riser/` | 25 | 스펙트럼 중심이 600Hz → 5~7kHz로 치솟는 **휘익(상승 휘슬/스윕)** | 컷 전환 직전 0.4~0.6초, 다음 장면을 당겨오는 자리 |
| `riser_impact/` | 5 | 휘익 뒤에 **쿵**이 붙은 한 덩어리 | 장면 전환 + 사건이 터지는 순간 (가장 쓰기 좋음) |
| `riser_rumble/` | 4 | 휘익 + 저역 럼블이 깔려 이어짐 | 위기 고조 구간 진입 |
| `impact/` | 5 | 25~120Hz가 45~58% 차지하는 **저역 임팩트(쿵)** | 반전·폭로 문장의 첫 글자 |
| `rumble/` | 1 | 1.3초짜리 지속 **저역 드론(브라암)** | 긴장 유지 베드, 반전 직전 |
| `hit/` | 18 | 중저역 짧은 타격/스팅 | 문장 강조, 잔펀치 |

## 참고 영상의 배치 밀도 (실측)

- 3편 모두 **40초 안팎에 효과음이 17~21회** — 대략 **2초에 한 번**꼴이다.
- 리듬이 있는 BGM은 쓰지 않는다(비트 주기성 0.04~0.09로 사실상 없음). **효과음 자체가 배경 역할**을 한다.
- 무음 구간이 거의 없다(RMS 1퍼센타일 0.03~0.045) — 나레이션 사이사이를 효과음이 계속 메운다.
- 전형적 패턴: `riser` 로 당기고 → 컷 지점에서 `impact` 로 때리고 → 다음 문장까지 `rumble` 이 깔린다.

`manifest.json` 에 파일별 원본·시작시각·길이·분류가 들어 있다.
