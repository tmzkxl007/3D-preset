# 효과음 라이브러리 (합성)

`synth_sfx.py` 로 **직접 합성한** 효과음이다. 스크립트를 다시 돌리면 같은 파일이 그대로 나온다(시드 고정).
전부 `loudnorm=I=-16:TP=-1.5` 로 레벨을 맞췄다.

## 왜 합성인가 — 추출은 실패했다

처음에는 참고 숏폼 3편(`_sQKXLJwFyE`, `pOTb3oluokg`, `NRbCOEjBfoc`)에서 "나레이션이 없는 구간"을 골라
효과음 58개를 잘라냈다. **58개 전부에 그 채널의 한국어 나레이션이 섞여 있었다** — Speechmatics ASR로
라이브러리 전체를 검사해 확인했다("눈이 멀거", "부리부리뼈", "3D 프린터가" 등이 그대로 들어 있었다).
그 영상들은 말이 거의 끊기지 않아서, 무음처럼 보이던 구간이 실은 **문장 사이가 아니라 단어 사이**였다.

그래서 추출본은 버리고, 참고 영상에서 **측정한 스펙트럼 특성만** 남겨 같은 성격의 소리를 새로 합성했다.
남의 채널 오디오를 그대로 싣지 않아도 되는 이점도 있다.

## 분류

| 폴더 | 개수 | 합성 방식 | 쓰는 자리 |
|---|---|---|---|
| `riser/` | 8 | 백색잡음을 시간가변 가우시안 대역으로 깎아 중심주파수를 890Hz→7.1kHz로 상승 + 톤 스윕 + 8~12kHz 에어 | 컷 전환 직전 0.5~0.65초 |
| `riser_impact/` | 5 | riser 뒤에 impact를 0.05초 겹쳐 붙임 | 장면 전환 + 사건이 터지는 순간 |
| `riser_rumble/` | 3 | riser 뒤에 rumble을 0.18초 겹쳐 붙임 | 위기 고조 구간 진입 |
| `impact/` | 5 | 95→36Hz로 떨어지는 사인 + 190Hz 몸통 + 4ms 클릭 + 중고역 에어, tanh 새추레이션 | 반전 문장의 첫 글자 |
| `rumble/` | 3 | 58Hz 중심 저역 잡음에 1.4Hz LFO + 옅은 중역 텍스처, 1.2~1.4초 | 긴장 유지 베드 |
| `hit/` | 6 | 175Hz 감쇠 사인 + 420Hz 잡음 + 3.8kHz 브라이트 트랜지언트 | 문장 강조 |

## 참고 영상의 배치 밀도 (실측 — 이건 그대로 쓸 만하다)

- 3편 모두 **40초 안팎에 효과음이 17~21회** — 대략 **2초에 한 번**꼴.
- 리듬이 있는 BGM은 없다(온셋 자기상관 주기성 0.04~0.09). **효과음이 배경 역할을 한다.**
- 전형적 패턴: `riser` 로 당기고 → 컷 지점에서 `impact` 로 때리고 → 다음 문장까지 `rumble` 이 깔린다.
